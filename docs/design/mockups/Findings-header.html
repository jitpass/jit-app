what changes
  • headline"10 secrets in your vault", not "10 of 26 secrets protected". The denominator mixed vaulted secrets with deduplicated tokens in transcripts, and read as a to-do that had no list. The vault count is the one number every user understands.
  • to-do linesOne line per tier with something in it. Dot in the tier's colour, the card's own numbers, the card's own verb as a link. Nothing here is computed for the header alone: a number in the header must be a number on a card.
  • verbsThe sentence ends in what to do. "clear the copies" is Clean Caches, "redact them" is Redact All. A line never says "protect" when the fix is not jit migrate.
  • fixtures"8 test fixtures, not counted" moves into the run sentence. It was a tab and a footer count and never a to-do.
  • barThe coverage bar goes. It drew 10/26, a ratio the new headline no longer states. If a picture is wanted, it is the vault window's, not this one's.
  • footerUnchanged. Rows and files read, as today. The footer counts rows; the header counts things to do; they no longer pretend to be the same.
  • enginejit scan prints the same lines. secrets_total / secrets_protected stay in the NDJSON for the score; the human report leads with the vault count and the to-do lines, each naming its command.
to confirm
  • wording"clear the copies" vs the button's "Clean Caches…". The link and the button should be the same words. Either the button becomes "Clear Copies…" (it deletes cache files that hold copies), or the line says "clean the caches".
  • All pillKeep "All 60"? It is the only place the row total appears besides the footer. I kept it; it could go.
  • the 12The two transcripts are jit's own research sessions. The scanner is right to flag them and Redact All is one click. Nothing in the header should special-case them.
