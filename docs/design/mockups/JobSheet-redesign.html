New AI Job, redrawn

Pick a profile, pick a script, approve. Everything else jit already knows.

The sheet as built asks you to type four things jit can find by itself, and it drifted from the approved frame C and from the design system. This redraws it the way New Grant works: the profiles jit finds on the Mac, no folder picker, the sentence filling in as you choose. It replaces frame C in Jobs.html; frames D and E (a proposal, a refusal) keep their shape.

The sheet, three moments

One sheet, read top to bottom before a Touch ID. The sentence is the Touch ID's own words; a blank is grey until you fill it.

Editing a job

A job is changed by approving it again under the same name, which the service already does (replace). So Edit is the same sheet, opened filled in from the job, with one Touch ID when you approve the change. Until then the job runs as it was.

What changes from the build

Each line is something the sheet in your screenshot does that the design system or the approved frame C does not.

  • BuiltFour blanks to fill: Name, Folder (Choose…), a typed command, then the profile is inferred from the folder.
    RedrawnTwo picks: a profile from the list, then a script from its folder. The folder starts at the profile's and is changed only when the script is elsewhere; the name is filled in from the script.
  • BuiltThe sentence says "with no secrets" and the Secrets row says "This folder has no jit profile" before any folder is chosen.
    RedrawnBlanks stay grey (app-label-3) until chosen, as New Grant's do. No row claims anything that has not been checked.
  • Built"No folder chosen" and "None" in mono, and the Runs placeholder reads like a value.
    Redrawnmono only for a real path or a command. A popup's label is its current value.
  • BuiltTwo Secondary "Choose…" buttons inside rows, one for an output folder.
    RedrawnOne Quiet Choose…, the kind a row takes, for the folder. No output folder: an AI tool that can read the script knows where it writes; the terminal keeps --output.
  • BuiltName is the first field, empty, before you know what the job is.
    RedrawnName is the last row, filled in from the script (notion-list-guest-users), and can be typed over.
  • BuiltFrame C's command box was dropped for a text field.
    RedrawnThe command is always visible in mono: in the Runs list, then as the popup's value.

How it maps to the build

  • 1
    Profiles: the grant sheet's discovery.ProfileDiscovery.discover, as New Grant calls it. A profile from ~/.jit/profiles has no folder of its own; picking one shows a Quiet "Choose folder…" where the folder line is, the one case a folder is chosen.
  • 2
    Scripts: suggestions, never decisions.The top level of the folder: *.py (through .venv/bin/python when that exists, else python3), *.sh, *.js/*.mjs through node, and any executable file. What it picks is only the command line; job_preview still checks it, and a refusal shows as frame E.
  • 3
    No new op.The spec sent is the same job_allow spec the CLI sends, so the app is still never the only way to make a job. The CLI's jit job allow is unchanged.
  • 4
    A proposal (frame D) skips C1 and C2.It arrives with profile and command filled in, so it opens straight at C3 with the amber banner.
